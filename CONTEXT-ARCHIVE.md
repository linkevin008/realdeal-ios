## Listing form: country dropdown, geocoding, required specs 10-06-2026
- Country is a Picker fed by `GET /api/v1/config/countries` (backend = single source of truth; US/CA defaults so mocks and offline keep working); stores ISO alpha-2 codes, displays localized names; selection reconciles if the backend drops a country
- Postal field adapts to country: "ZIP Code" for US, "Postal Code" otherwise; validation mirrors the server
- **Coordinates are geocoded from the address** (CLGeocoder via injectable closure) on create/update — the manual Location Coordinates section is gone; geocode failure blocks save
- Specifications required: bedrooms/bathrooms Pickers, square feet numeric
- DTOs renamed `zipCode` → `postalCode` (wire field `postal_code`)

## Remove broken RealDealUITests target 10-06-2026
- Root cause of "Failed to load the test bundle": the `RealDealUITests` native target had an empty `fileSystemSynchronizedGroups = ()` and no source folder on disk, so it produced an `.xctest` bundle with no executable
- Deleted the dead target from `project.pbxproj` (file reference, Products entry, native target, build phases, dependency + container proxy, TargetAttributes, configs) — the project has no shared scheme, so Xcode's autogenerated scheme pulled the broken target into every test run
- Full `xcodebuild test` now passes without `-only-testing:RealDealTests`
