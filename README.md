# Real Estate Listings iOS Application

A native iOS application for real estate property listings built with SwiftUI, following MVVM architecture with the Repository pattern.

## Project Setup

This project has been initialized with:

✅ SwiftUI app structure
✅ Core Data stack with persistent container
✅ MVVM architecture with Repository pattern
✅ Protocol-oriented design for services and repositories
✅ Core data models (Property, UserProfile, Favorite, PropertyFilters)
✅ SwiftCheck dependency for property-based testing
✅ Comprehensive error handling utilities

## Project Structure

See `RealEstateListings/README.md` for detailed project structure.

## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Getting Started

1. Open the project in Xcode
2. Build and run the project
3. The app uses Core Data for local persistence
4. Property-based tests use SwiftCheck framework
